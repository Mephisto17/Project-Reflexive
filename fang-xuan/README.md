# Xuan Fang — personal homepage

English/Chinese personal academic homepage for Xuan Fang (方轩), a doctoral student focusing on AI for mathematics at the School of Mathematical Sciences, Fudan University. The biography, education, research interests, email, and portrait were provided by Xuan Fang.

Website: <https://mephisto17.github.io/Project-Reflexive/fang-xuan/>. The repository's Pages workflow publishes this page after a successful build on `main`.

## Preview

From the repository root:

```sh
npm run dev
```

Open `http://localhost:5173/fang-xuan/`. `npm run build` copies the personal site to `dist/fang-xuan/` alongside the existing Project Reflexive site. All assets use relative paths, so the page works below a GitHub Pages repository path.

## Edit

- `index.html`: English content, biography, paper list, and navigation.
- `style.css`: desktop, mobile, print, and reduced-motion styles.
- `profile.js`: Chinese copy, language selection, and BibTeX copying.
- `publications.bib`: downloadable citations; keep these consistent with `profile.js`.
- `assets/xuan-fang.jpg`: provided portrait, re-encoded without source metadata. No synthetic alteration or added detail.

No enrollment dates, supervisor, degrees beyond those described, or journal acceptances are inferred. The papers are labeled as arXiv preprints. Bibliographic titles remain in their original English when the interface is in Chinese.
